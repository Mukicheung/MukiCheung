## 正在做的东西

### [Let Me Drive](https://letmedrive.cn) · 网页键盘驱动大合集

打开网页，为键盘改键、录宏、调灯光、设置磁轴参数。让硬件设置更容易上手，也让 Mac 用户少折腾一点。

[打开使用 →](https://letmedrive.cn) · [查看支持的键盘](https://letmedrive.cn/keyboards) · [项目与反馈](https://github.com/tainanzhui/letmedrive)

### [Epidemic Sound 原生中文](https://github.com/tainanzhui/epidemic-sound-zh)

给创作者常用的音乐网站加一层更自然的中文界面。用本地词典翻译音乐风格、情绪和操作提示，在显示中文的同时保留原始业务文本与参数。

从自己找配乐时的困扰出发，做成可以直接安装的油猴脚本和浏览器扩展。

[安装与使用 →](https://github.com/tainanzhui/epidemic-sound-zh#readme) · [下载最新版本](https://github.com/tainanzhui/epidemic-sound-zh/releases/latest)
